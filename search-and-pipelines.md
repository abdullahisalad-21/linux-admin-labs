# Searching and Pipelines in Linux

## Searching with grep
grep "error" logfile.txt grep -r "keyword" /var/log

## Using pipelines
ls -l  grep ".txt" cat file.txt  wc -l

## Redirecting output
command > file.txt command >> file.txt command 2> errors.txt

## What I Learned
- How to search inside files  
- How to combine commands  
- How to redirect output and errors
